# On-Time Taxi — Brand Assets

## Files
- `logo.svg` — primary wordmark + roof-light icon

## Colors
| Name | Hex | Use |
|---|---|---|
| Brand Navy | #0a2540 | Primary background, dark text |
| Taxi Yellow | #FFCC00 | Accent only — CTA highlights |
| Trust Blue | #1a4d8f | Links, secondary buttons |
| Off-White | #F7F9FC | Light backgrounds |
| Charcoal | #1F2937 | Body text |

## Typography
- Headlines: **Inter ExtraBold**
- Body: Inter Regular
- Fallback: system-ui, sans-serif

## Don'ts
- Don't recolor the logo
- Don't stretch or skew
- Don't place on busy photos without a solid panel behind it
- Don't use Comic Sans for anything, ever

## Usage
Logo SVG is in this folder and at `marketing-web/public/logo.svg`. For raster, export at 1x/2x/3x from SVG.
