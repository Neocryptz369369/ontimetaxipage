# On Time Taxi — Brand System

> **Tagline:** Everyone needs a ride.
> **Promise:** Anywhere pickup. Anywhere drop-off. Even out of state, same day.
> **Launch market:** Clark County, Indiana

## Color palette (default — swap once logo is shared)
| Token | Hex | Use |
|---|---|---|
| `--ott-yellow` | `#FFC629` | Primary brand (taxi heritage) |
| `--ott-black`  | `#0E0E10` | Text, headers, driver app base |
| `--ott-white`  | `#FFFFFF` | Backgrounds |
| `--ott-slate`  | `#1F2430` | Cards, surfaces (dark mode) |
| `--ott-green`  | `#1DB954` | Success, "on the way" |
| `--ott-red`    | `#E5484D` | Cancel, SOS |
| `--ott-gray`   | `#8A8F98` | Muted text, dividers |

## Typography
- **Display / Headings:** Inter Tight (700/800) — modern, confident
- **Body / UI:** Inter (400/500/600)
- **Numbers (fare, ETA):** Inter (tabular)

## Voice
Plain-spoken, local, no-nonsense. "We'll be there in 6 minutes." Not "Your ride is on its way!"
